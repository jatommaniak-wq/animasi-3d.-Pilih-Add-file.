Bahasa mengikuti permintaan pengguna (default Indonesia; kalau diminta Inggris, pakai bahasa Inggris percakapan yang sederhana). Angka ditulis dengan huruf di naskah ("twenty five") agar dibaca benar oleh suara AI, lalu ubah di `captions` (`{'twenty five': '25'}`). **Tunjukkan naskah dan tunggu persetujuan ("buat video") sebelum menulis animasi.** 2. **Fakta.** Cek setiap klaim (pakai pencarian web kalau ada). Teks lain di layar hanya untuk nama konsep penting (`label()`), jangan kalimat. - Benturan = `burst` + `shake` + `flash` + `sfx('impact')`. Muncul = `popIn` + `sfx('swish')`. Ketemu jawaban = `sparkle` + `sfx('ding')`. - SFX di bawah suara (sudah diatur), musik pelan dan otomatis mengecil saat ada suara. Jangan pakai bunyi seperti laser. - Tanpa em dash di layar. ## Tata letak (kanvas 1080 × 1920) - **Pita teks layar y 1250 sampai 1420. Wajah tidak boleh masuk.** Untuk Dodi berdiri di `y` dengan ukuran `s`: dagu = `y − 0.565·s`, ubun-ubun = `y − 0.93·s`. Pastikan dagu ≤ 1240 (atau seluruh kepala di bawah 1430). - Contoh aman: `s: 860, y: 1640` (close-up), `s: 600, y: 1590`, `s: 380, y: 1380`. - Area aman Instagram/TikTok: x 100 sampai 980, y 220 sampai 1500. Properti penting di dalamnya. - Duduk (`pose: 'sit'`): kaki menyentuh tanah kalau `y = tanah + 0.15·s`; pantat ada di `tanah − 0.15·s` (gambar bangku/batu setinggi itu). - Hadap kiri: `flip: -1`. Tampak samping otomatis untuk pose `run`, `walk`, `sit`, `stand`. ## API ringkas (untuk menulis blok REEL) **Isi REEL** ```js const REEL = { title, file, lang: 'en-US'|'id-ID', voice: 'am_michael', voiceSpeed: 1, music: 'ceria'|'misteri'|'tenang'|false, script: [ 'kalimat 1', ... ], captions: { 'twenty five': '25' }, speed: 1 }; ``` - `captions` = ganti teks layar (mis. angka ditulis angka). `speed` > 1 memperlambat perkiraan tempo kalau suara belum dibuat. - `voice` = suara Kokoro awal (pengguna bisa mengganti di menu). Pilihan: `am_michael` (pria US, netral, default), `am_adam`, `am_fenrir` (berat, cocok sejarah/misteri), `am_puck` (ceria), `af_heart` (wanita US), `af_bella`, `af_nicole` (lembut), `bm_george` (pria UK, cocok sejarah), `bm_fable`, `bf_emma` (wanita UK). Kokoro hanya untuk bahasa Inggris; untuk video bahasa Indonesia pengguna merekam suaranya sendiri. - `music`: `misteri` untuk sejarah/misteri, `ceria` untuk fakta lucu/sains, `tenang` untuk topik sedih/serius. **Adegan** ```js scene({ s: 3, w: 0, off: 0, tr: 'whip'|'cut'|'flash', draw(ctx, lt, t, d) { ... } }); ``` - Adegan mulai saat kata ke-`w` kalimat ke-`s` diucapkan (adegan pertama selalu di 0). `tr` = transisi KELUAR adegan ini. - `lt` = detik sejak adegan mulai, `t` = detik global, `d` = durasi adegan. - `T(s, w)` = detik saat kata ke-w kalimat ke-s mulai (w negatif dihitung dari belakang, `T(2,-1)` = kata terakhir). `TE(s, w)` = saat kata itu selesai. **Selalu pakai `T()` untuk mengatur aksi ke kata**, karena waktunya ikut menyesuaikan suara yang direkam. - `sfx(jenis, s, w, offset = 0, gain = 1)` di luar `scene`. Jenis: `whoosh swish thud impact tap ding sparkle rise step cash buzz`. Whoosh transisi whip sudah otomatis. **Kamera & gerak** - `CAM(ctx, {x, y, z, r}, par)`: titik (x,y) dunia di tengah layar, `z` zoom, `r` miring. Panggil `CAM(ctx, cam, .05)` untuk langit, `.2` awan, `.5` bukit jauh, `1` dunia depan (parallax). - `handheld(t, amp)` → [dx, dy]. `shake(t, amp, freq)`. - `kf(t, [[t0, v0], [t1, v1, easing?], ...])` keyframe (angka atau array). `popIn(t, t0, dur)` 0→1 memantul. `inv(a, b, v)` 0..1. `lerp`, `clamp`, `ease`, `easeOut`, `easeIn`, `backOut`, `elastic`, `rng(seed)`. **Dodi** ```js drawDodi(ctx, { x, y, s, t, pose, face, look: [x, y], turn, flip, tilt, lean, air, squash, alpha, talk, view: 'back', hold(ctx, hx, hy, ang) {}, acc(ctx, hx, hy, turn) {}, arms, legs, pal, hair, glasses, shadow, seed }); ``` - Selalu isi `t` (untuk kedip & animasi pose). `y` = posisi telapak kaki. `s` = tinggi badan dalam piksel. - `pose`: `idle wave point pointUp cheer shock think shrug hips explain hold facepalm sad jump fall run walk stand sit`. - `face`: `smile happy grin laugh smug shock think angry sad worried neutral sleepy determined wow scared`, atau objek `{ e: 'open|wide|happy|closed|half|angry', b: 'flat|up|high|angry|worry|one', m: 'smile|grin|laugh|smirk|teeth|O|hmm|frown|wobble|flat' }`. - `look` arah bola mata (−1..1). `turn` −1..1 memutar wajah. `air` = piksel melayang (bayangan tetap di tanah). `talk: true` = mulut bergerak ikut suara. - `hold(ctx, hx, hy, ang)` menggambar benda di tangan kanan, dalam satuan badan (1 = tinggi badan). Contoh HP: `rrect(ctx, hx - .03, hy - .1, .06, .11, .01); ctx.fillStyle = '#222'; ctx.fill();` - `arms: { R: [a1, a2] }` sudut bahu & siku manual, atau `R: { ik: [x, y] }` tangan ke titik (satuan badan, kaki di 0, kepala ~ −0.75). - Tokoh lain: `drawDodi(ctx, { ...CAST.RINA, x, y, s, t, ... })`. Tersedia `CAST.RINA` (rambut panjang, hoodie biru), `CAST.BUDI` (rambut pendek, hoodie hijau), `CAST.PAK` (rambut putih, kacamata). Bisa juga `pal: { top: '#2f7de1', top2: '#1f55a6', hair: '#111' }`, `hair: 'wavy'|'short'|'long'|'none'`, `glasses: false`. **Dunia** (koordinat dunia, panggil setelah `CAM`) `sky(ctx, atas, bawah)`, `sky3(ctx, a, b, c)`, `sun(ctx, x, y, r, t, warna, glow)`, `cloud(ctx, x, y, s, seed, alpha)`, `ground(ctx, y, c1, c2)`, `hill(ctx, cx, y, w, h, warna)`, `tree(ctx, x, y, s, t)`, `bush(ctx, x, y, s)`, `house(ctx, x, y, s, dinding, atap)`, `city(ctx, dasarY, seed, warna)`, `room(ctx, { floorY, wall, floor, window, winX, winY, winSky, frame })`, `table(ctx, x, y, s)`, `laptop(ctx, x, y, s, layar(ctx, w, h))`, `phone(ctx, x, y, s, rot, layar(ctx, w, h))`, `board(ctx, x, y, w, h, judul)`, `arrow(ctx, x1, y1, x2, y2, progres, warna, tebal, lengkung)`, `bars(ctx, x, y, w, h, nilai[], progres)`, `label(ctx, teks, x, y, size, bg, fg, skala)`, `icon(ctx, nama, x, y, s, t)` dengan nama `q ex check cross bulb heart coin money clock star zzz fire`. **Efek** `burst(ctx, x, y, r, n, warna)`, `flash(ctx, alpha)`, `sparkle(ctx, x, y, r, a)`, `puff(ctx, x, y, r, a)`, `sweat(ctx, x, y, s, a)`, `speedLines(ctx, t, a)`, `motionLines(ctx, x, y, arah, panjang)`. **Bentuk dasar** `circle`, `ellipse`, `rrect`, `poly`, `line`, `fs(ctx, isi, tebal, garis)`, `text(ctx, str, x, y, size, isi, garis, tebalGaris)`. Properti khusus video (prisma, molekul, kapal, dll.) ditulis sebagai fungsi di blok REEL, lihat contoh `molecule()` dan `wave()`. ## Daftar cek sebelum menyerahkan - [ ] Jumlah `scene` ≈ jumlah kalimat, indeks `s` urut naik, semua `s` < jumlah kalimat, `w` < jumlah kata kalimat itu. - [ ] Setiap adegan menggambar latar penuh dulu (`sky`/`room`/warna) supaya tidak ada area hitam saat kamera bergerak. - [ ] Dagu Dodi ≤ 1240 di setiap adegan (rumus di atas). - [ ] Setiap aksi penting dikunci ke kata dengan `T(s, w)`, bukan detik mati. - [ ] Tidak ada kalimat panjang di layar; hanya `label()` untuk nama konsep. - [ ] ENGINE tidak diubah satu karakter pun.
